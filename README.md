# Proyecto-Final-Programacion-Paralela-y-Concurrente
Optimización de rendimiento en C++ mediante OpenMP. Implementamos la generación paralela de fractales (Mandelbrot 8K) y filtros de convolución 2D. Comparamos planificadores de carga, técnicas de sincronización, mitigación de False Sharing y optimización de caché mediante afinidad de hilos y vectorización SPMD.
